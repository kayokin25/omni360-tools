Подбор адресов

Забирает объекты из справочника 2ГИС вокруг центра города и снимает дубли по координатам. По умолчанию работает быстро — одним широким поиском; если нужна полнота, включается дополнительный обход по сетке.

Что искать
За один раз — один запрос и один город. Списки через запятую («Пятёрочка, Магнит» или «Казань, Уфа») справочник воспримет как одну строку и вернёт ерунду. Нужно несколько — прогоните по очереди.
