Подготовка отчётности

Разные клиенты — разные форматы отчётов. Внутри — несколько отдельных сценариев, переключайтесь вкладками ниже.

Готовит эфирную справку к отправке клиенту: убирает столбец «Комиссия платформы», добавляет нумерацию «№» и ставит показанные объекты (Кол-во показов > 0) первыми, отсортированными по GID — непоказанные остаются внизу в своём порядке. Стили, ширина столбцов и ссылки на фото не трогаются — правится только то, что нужно.

Замена нулей в OTS
Часть экранов передаёт 0 вместо реального OTS. Если для пары «город × тип конструкции» ниже задано значение — 0 заменяется на него; для остальных пар 0 остаётся 0. Таблица разовая для каждой кампании — присылает клиент/оператор.
Диапазон дат — необязательно
По умолчанию — весь период, что есть в статистике. Если система выгружает данные за месяцы вперёд «на всякий случай» — здесь можно обрезать до нужных дат (например, отдать клиенту только закрытый месяц).
