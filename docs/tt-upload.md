# Как загружать ТТ на Диск, чтобы инструмент их находил

Инструкция для того, кто выгружает технические требования операторов и
складывает их в общую папку. Инструмент «Сбор технических требований» в панели
Omni360 читает эту папку и сам подставляет ссылку на ТТ в отчёт по адресной
программе. Чтобы он находил файлы, важны две вещи: **каждый файл опубликован**
и **имя файла составлено по правилу**. Всё остальное — на ваше усмотрение.

Папка: <https://disk.360.yandex.ru/d/vxW2CKH5WQhofQ>

---

## 1. Выгрузить ТТ из системы

Способ любой удобный. Рабочий вариант — создать на **тестовом аккаунте**
кампанию и по мере выгрузки ТТ менять в ней инвентарь: так вы пройдёте по
операторам и форматам, ничего не пропустив.

Заодно сразу выписывайте себе, у каких операторов ТТ вообще нет — этот список
пригодится (см. пункт 6).

## 2. Положить файл в папку

Складывать можно как удобно, в том числе по подпапкам: инструмент обходит
вложенность сам. Формат файла тоже любой — `.pdf`, `.png`, `.jpg`. Расширение
в разборе имени не участвует.

## 3. Опубликовать каждый файл по отдельности

Это обязательно, и это самая частая причина, по которой ссылка не появляется.

Публикации самой папки **недостаточно**: у файла внутри неопубликованной папки
нет собственной постоянной ссылки, и инструмент такой файл пропустит. Нужно на
каждом файле: правой кнопкой → «Поделиться» / «Скопировать ссылку».

Проверить себя просто: в логе инструмента есть строка вида
`Диск: файлов 95, с постоянной ссылкой 95`. Если второе число меньше — какие-то
файлы не опубликованы.

## 4. Назвать файл

Имя строится так:

```
<Название оператора> <под что этот файл>.<расширение>
```

Есть три варианта второй части — от самого точного к самому общему:

| Вариант | Пример имени | Когда сработает |
|---|---|---|
| Разрешение | `Русс 1440х720.pdf` | для экранов ровно 1440×720 |
| Соотношение сторон | `Аффикс Групп 2:1.jpg` | для любых экранов с соотношением 2:1 |
| Общее | `LBL общее.png` | для всех остальных экранов этого оператора |

Инструмент ищет в этом же порядке: сначала точное разрешение, потом
соотношение сторон, потом общий файл. То есть общий файл не мешает точным — он
подставляется только там, где точного не нашлось.

**Если у оператора одно ТТ на всё** — достаточно `общее`, а можно и вообще без
второй части: `Инсайт.jpg` работает так же.

### Название оператора

По умолчанию берите его **из колонки «Оператор» в адресной программе** —
копированием, а не по памяти. Именно с этой колонкой инструмент и сверяет имя
файла.

**Исключение — операторы из таблицы ниже.** У них в скрипте прописано
отдельное имя для файлов, и называть файл нужно так, как в правой колонке:

| В адресной программе | В имени файла |
|---|---|
| Russ Outdoor | `Русс` |
| MAER (Outdoor) · МАЕР (Outdoor) · test@maergroup.ru | `МАЕР` |
| Реклама Центр Outdoor | `РЦ` |
| Мособлреклама | `Мособл` |
| Sunlight Outdoor | `Санлайт` |
| Инсайт Медиа | `Инсайт` |
| 3 Арт | `3Арт` |
| РА Zvenboard | `Zvenboard` |
| РА Оди Медиа | `Оди Медиа` |
| АРК Медиа | `АРК` |
| Рекламное агентство «ГиГ» | `ГиГ` |
| Постекс | `Постекст` |
| Рекламная группа 6х3" | `Рекламная группа` |

Верхняя часть списка — исторические сокращения: файлы давно названы коротко, и
скрипт это знает. Нижняя (начиная с «3 Арт») — расхождения, которые нашли
позже: ТТ там лежали, но не находились, и вместо переименования файлов в скрипт
добавили эти строки.

Если хочется навести порядок и назвать файл как в АП — так делать можно, но
**не в одиночку**: строку нужно одновременно убрать из скрипта, иначе ссылка
перестанет находиться. Напишите Александре.

Что не важно:

* регистр — `русс`, `Русс`, `РУСС` одинаковы;
* знаки препинания, кавычки, скобки, дефисы — `РА "ЦВЕТ"`, `РА ЦВЕТ`,
  `РА-ЦВЕТ` читаются одинаково;
* лишние пробелы.

Что важно:

* **слова нельзя терять и добавлять.** `РА Оди Медиа` и `Оди Медиа` — для
  инструмента разные операторы. Из-за этого несколько ТТ уже пролежали в папке
  незамеченными;
* **раздельное написание ≠ слитное.** `3 Арт` и `3Арт` — разные;
* **никаких приписок перед названием.** `ТТ Русс 1440х720.pdf` не сработает:
  всё, что стоит до разрешения, считается названием оператора, и оператор
  получится «ТТ Русс».

Приписки **после** разрешения безобидны — `Русс 1440х720 актуальное.pdf`
прочтётся нормально. Но лучше без них.

### Как писать разрешение и соотношение

* Разрешение — два числа через `x`: `1440x720`. Русская `х`, латинская `x`,
  большие буквы и знак `×` — всё подходит, пробелы вокруг тоже: `1440 х 720`.
* Соотношение — только **через двоеточие**: `2:1`. Записи вроде `3к1`, `3х1`
  или `3 к 1` инструмент соотношением не считает — такой файл он воспримет как
  общий и, скорее всего, потеряет.

### Можно сразу и то, и другое

`Мособл 960х480 2:1.jpg` закроет и экраны ровно 960×480, и любые другие
экраны 2:1 у этого оператора. Удобно, когда ТТ одно на всё соотношение, но
хочется гарантировать точное совпадение для основного размера.

А вот **смешивать `общее` с числами не надо** — `Оператор 720х360 общее.png`
формально сработает, но потом никто не поймёт, что это за файл.

## 5. Проверить себя

Прогоните инструмент на своей выгруженной адресной программе:

1. откройте «Сбор технических требований» в панели;
2. положите файл АП, нажмите «Собрать ТТ»;
3. смотрите на плитку **«со ссылкой N из M»** и вкладку **«Без ссылки»**.

Каждая строка во вкладке «Без ссылки» — это либо ТТ, которое вы ещё не
загрузили, либо файл, названный не так. Проверять глазами всю папку не нужно,
инструмент сам покажет, чего не хватает.

## 6. Когда не разбираться самому, а спросить

Три случая, где имя файла ни при чём и чинится не в папке:

1. **В названии оператора есть числа через «х»** — например
   `Рекламная группа 6х3`. Инструмент прочитает «6х3» как разрешение 6×3 и
   обрежет название. Такому оператору нужен алиас в скрипте.
2. **Оператор называется в папке иначе, чем в системе,** и переименовать файл
   нельзя (например, ссылку уже разослали). Тоже лечится алиасом.
3. **Пустая длительность в отчёте** (вкладка «Без длительности») — это не про
   ТТ вообще. Значит, связки «оператор + формат» ещё нет в справочнике
   длительностей, её нужно туда добавить.

## Чего не делать

* **Не заливать один и тот же ТТ дважды под разными именами.** Если два файла
  претендуют на одну и ту же связку, в отчёт попадёт непредсказуемо какой. В
  папке уже есть такая пара: `Аляска 576х288` и `РА Аляска 576х288`.
* **Не удалять и не загружать заново без нужды.** У нового файла будет другая
  постоянная ссылка, а старая останется в уже отправленных клиентам выгрузках и
  будет вести в пустоту. Если ТТ обновилось — обновляйте файл, сохраняя имя.
* **Не переименовывать чужие файлы «чтобы было аккуратнее».** Сначала
  посмотрите, не сломает ли это подстановку: у оператора могут быть и точные, и
  общие файлы, и они работают в паре.

## Короткая версия

1. Выгрузил ТТ.
2. Положил в папку — хоть в подпапку.
3. **Опубликовал файл** (не папку).
4. Назвал `Оператор разрешение`, `Оператор соотношение` или `Оператор общее`,
   скопировав название оператора из колонки «Оператор» в АП.
5. Прогнал инструмент, посмотрел вкладку «Без ссылки».
